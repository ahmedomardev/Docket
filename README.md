# 🧾 SnapReceipt

**SnapReceipt** is a lightweight, mobile-first receipt management application built with **Python** and **Flet**. It helps you digitize receipts, track return deadlines, and manage item warranties with built-in native Android notifications.

## ✨ Features

- 📸 **Built-In Document Camera Scanner:** Capture multi-page receipts using your device camera.
- 🗂️ **Receipt Vault:** Store and categorize your receipts locally with visual indicators showing remaining return days.
- 🔔 **Dual Expiration Alerts:** Calculates deadlines and sends native Android notifications for both **Return Windows** and **Warranty Coverage**.
- 📋 **Detailed Inspector:** Review notes, purchase categories, exact expiration dates, and high-resolution photo attachments.
- 🔒 **100% Offline & Private:** All data (`receipts.json`) and images (`receipt_images/`) remain on your local device.
