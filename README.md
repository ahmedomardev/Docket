# Docket

**Docket** is a simple, modern application built to help you keep track of everyday receipts, return windows, warranties, and vehicle maintenance parts in one clean ledger.

## ✨ Features

* **Receipt Tracking**: Save store names, costs, categories, and custom notes.
* **Return & Warranty Management**: Easily monitor return deadlines and warranty expiration dates.
* **Car Part Maintenance**: Track vehicle parts, service intervals, and kilometers since installation.
* **Photo Attachments**: Snap and attach photos of your receipts or parts directly to your records.
* **Offline Local Storage**: Keep all your data secure and private directly on your device.
